## Modelo de Entidades

O bloco YAML abaixo é a fonte da verdade do modelo de U2. Tipos são lógicos, não de banco. Nomes de entidade, atributo e valor permitido são identificadores e ficam em inglês; as descrições ficam em português. Referências a User, Sector, Category, Status e Priority apontam para entidades de U1, sempre no sentido do grafo (DB-01).

```yaml
entities:
  - name: Ticket
    owner_block: Tickets
    description: Solicitação acadêmica aberta por um Aluno ou Professor e acompanhada até o encerramento.
    attributes:
      - name: id
        type: uuid
        required: true
        unique: true
      - name: number
        type: integer
        required: true
        unique: true
        constraints:
          - global sequence generated by the database at creation; never reused or changed
          - exposed as the text reference made of a hash sign followed by the number, with no leading zeros
          - gaps may appear when a creation is rolled back
      - name: title
        type: text
        required: true
        min_length: 5
        max_length: 120
        constraints:
          - surrounding spaces removed before validation
      - name: description
        type: text
        required: true
        min_length: 10
        max_length: 2000
        constraints:
          - surrounding spaces removed before validation
      - name: requesterId
        type: reference
        references: User.id
        required: true
        constraints:
          - the requester has role STUDENT or PROFESSOR at creation time
          - never changes
      - name: assigneeId
        type: reference
        references: User.id
        required: false
      - name: categoryId
        type: reference
        references: Category.id
        required: true
        constraints:
          - chosen at creation; never changes
      - name: sectorId
        type: reference
        references: Sector.id
        required: true
        constraints:
          - derived from the category at creation; changed only by transfer
      - name: statusId
        type: reference
        references: Status.id
        required: true
      - name: priorityId
        type: reference
        references: Priority.id
        required: true
      - name: openedAt
        type: timestamp
        required: true
      - name: updatedAt
        type: timestamp
        required: true
      - name: closedAt
        type: timestamp
        required: false
        constraints:
          - set when the status becomes CLOSED; cleared when the ticket is reopened
    entity_constraints:
      - closedAt is present exactly when the current status key is CLOSED
      - a ticket is never deleted
    relationships:
      - target: User
        cardinality: many-to-one
        direction: Ticket -> User (requester)
        optional: false
      - target: User
        cardinality: many-to-one
        direction: Ticket -> User (assignee)
        optional: true
      - target: Category
        cardinality: many-to-one
        direction: Ticket -> Category
        optional: false
      - target: Sector
        cardinality: many-to-one
        direction: Ticket -> Sector
        optional: false
      - target: Status
        cardinality: many-to-one
        direction: Ticket -> Status
        optional: false
      - target: Priority
        cardinality: many-to-one
        direction: Ticket -> Priority
        optional: false

  - name: TicketHistoryEntry
    owner_block: Tickets
    description: Registro imutável de uma mudança de status, responsável, setor ou prioridade.
    attributes:
      - name: id
        type: uuid
        required: true
        unique: true
      - name: ticketId
        type: reference
        references: Ticket.id
        required: true
      - name: field
        type: enum
        required: true
        allowed_values: [STATUS, ASSIGNEE, SECTOR, PRIORITY]
      - name: previousValue
        type: uuid
        required: false
        constraints:
          - identifier of the previous status, user, sector or priority; empty when there was none
      - name: newValue
        type: uuid
        required: false
        constraints:
          - identifier of the new status, user, sector or priority; empty when it was removed
      - name: justification
        type: text
        required: false
        min_length: 5
        max_length: 500
        constraints:
          - present exactly when field is SECTOR; copy of the justification of the transfer
      - name: authorId
        type: reference
        references: User.id
        required: true
      - name: occurredAt
        type: timestamp
        required: true
    entity_constraints:
      - entries are never updated nor deleted
      - previousValue and newValue are never both empty and never equal
    relationships:
      - target: Ticket
        cardinality: many-to-one
        direction: TicketHistoryEntry -> Ticket
        optional: false
      - target: User
        cardinality: many-to-one
        direction: TicketHistoryEntry -> User (author)
        optional: false

  - name: TicketSectorPassage
    owner_block: Tickets
    description: Período em que um chamado esteve num setor, do momento em que entrou até ser transferido.
    attributes:
      - name: id
        type: uuid
        required: true
        unique: true
      - name: ticketId
        type: reference
        references: Ticket.id
        required: true
      - name: sectorId
        type: reference
        references: Sector.id
        required: true
      - name: enteredAt
        type: timestamp
        required: true
      - name: leftAt
        type: timestamp
        required: false
      - name: justification
        type: text
        required: false
        min_length: 5
        max_length: 500
        constraints:
          - present exactly when leftAt is present; it is the justification of the transfer that ended the passage
      - name: transferredById
        type: reference
        references: User.id
        required: false
        constraints:
          - present exactly when leftAt is present
    entity_constraints:
      - each ticket has exactly one passage without leftAt, and its sectorId equals the ticket's current sectorId
      - passages are never deleted
    relationships:
      - target: Ticket
        cardinality: many-to-one
        direction: TicketSectorPassage -> Ticket
        optional: false
      - target: Sector
        cardinality: many-to-one
        direction: TicketSectorPassage -> Sector
        optional: false
      - target: User
        cardinality: many-to-one
        direction: TicketSectorPassage -> User (transferred by)
        optional: true

  - name: Notification
    owner_block: Notifications
    description: Aviso dentro do sistema sobre algo que aconteceu num chamado.
    attributes:
      - name: id
        type: uuid
        required: true
        unique: true
      - name: recipientId
        type: reference
        references: User.id
        required: true
      - name: ticketId
        type: reference
        references: Ticket.id
        required: true
      - name: kind
        type: enum
        required: true
        allowed_values: [MESSAGE_RECEIVED, STATUS_CHANGED, ASSIGNEE_CHANGED, SECTOR_CHANGED, TICKET_REOPENED]
      - name: read
        type: boolean
        required: true
        default: false
      - name: createdAt
        type: timestamp
        required: true
      - name: readAt
        type: timestamp
        required: false
        constraints:
          - present exactly when read is true
    entity_constraints:
      - a notification is never deleted
    relationships:
      - target: User
        cardinality: many-to-one
        direction: Notification -> User (recipient)
        optional: false
      - target: Ticket
        cardinality: many-to-one
        direction: Notification -> Ticket
        optional: false
```

## Resumo

| Entidade | Bloco dono | Para que serve | Invariantes principais |
|----------|-----------|----------------|------------------------|
| Ticket | Tickets | A solicitação e seu estado atual | Número visível sequencial e imutável, exposto como `#n`; setor muda só por transferência; `closedAt` presente exatamente quando encerrado |
| TicketHistoryEntry | Tickets | Cada mudança de status, responsável, setor ou prioridade | Imutável; guarda identificadores, resolvidos em nomes na leitura; entradas de setor trazem a justificativa |
| TicketSectorPassage | Tickets | Cada setor por onde o chamado passou (M1) | Exatamente uma passagem aberta, igual ao setor atual; justificativa e autor presentes só quando a passagem foi encerrada |
| Notification | Notifications | Aviso ao usuário | Nunca apagada; `readAt` presente exatamente quando lida |

**Estado derivado, não armazenado.** "Responsável indisponível" (Q6) não é atributo: é calculado na leitura, a partir do responsável e do setor atual do chamado, pelo serviço público de usuários de U1 (BR3.9 em `rules.md`).

**Diferenças em relação a `components.md` e `contract-summary.md`.**
- `Ticket.number` guarda o número sequencial; o campo `reference` do contrato continua texto e é derivado dele (Q1).
- `TicketSectorPassage.transferredById` é o nome do vínculo "quem executou a transferência" (DB-01 `transferred_by_id`).
- `TicketHistoryEntry.previousValue` e `newValue` guardam identificadores, não textos; `justification` repete a justificativa nas entradas de setor, para que o histórico a mostre (AC2.4.4).
